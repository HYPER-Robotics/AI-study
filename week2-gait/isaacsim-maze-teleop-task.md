## 2주차 — 팀별 시뮬레이션 실행

**기한: 2026년 9월 27일**

### 보행팀: 커스텀 미로에서 Go2 teleop

#### 과제

Isaac Sim에 간단한 미로를 직접 구성하고, 제공된 기본 보행 정책과 teleop 연결 예제를 사용해 Unitree Go2를 조종합니다. 미로는 평지와 넓은 통로, 몇 개의 코너 수준으로 구성합니다.

#### 제공되는 것

- 사용할 Isaac Sim·Isaac Lab 환경 및 버전 안내
- Go2 모델과 동작하는 기본 보행 정책
- 키보드 또는 ROS 2 속도 명령을 연결하는 teleop 예제
- 장면 구성, 충돌 설정, 로봇 실행 관련 교보재

#### GitHub 제출물

- 미로 장면 파일 또는 미로를 생성하는 코드와 필요한 자산
- 본인이 작성·수정한 실행 코드와 설정
- 환경을 불러와 조종하는 방법을 정리한 `README.md`
- **Go2가 직접 만든 미로에서 전진·회전·정지하는 teleop 영상**

#### 완료 시 설명할 내용

미로의 구성과 충돌 설정, 사용자 입력이 이동 명령과 로봇 동작으로 이어지는 흐름을 설명합니다.

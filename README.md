# HyperNova AI팀 3주 학습 안내

## 진행 방식

이번 학습은 **주차별 미니 과제 1개를 완성하는 방식**으로 진행합니다. 

- **참고용 교보재:** 공통·팀별 강의 및 참고 자료 링크를 Notion에 모아 제공합니다.
- **개인 학습 기록:** 각자 Notion 학습 페이지를 만들고, 학습 내용·시도한 방법·결과·막힌 점을 정리합니다.
- **정기 모임:** 주 1회 고정 모임에서 진행 상황과 결과를 공유하고, 질문 및 리뷰를 진행합니다. 요일·시간은 별도 안내합니다.
- **과제 제출:** 매주 AI-study GitHub 저장소에 PR을 올립니다.
- **리뷰 요청:** 매번 운영자를 Reviewer로 지정하고, PR 본문에도 운영자 계정을 멘션합니다. 계정은 별도 안내합니다.
- **완료 기준:** 결과물 제출과 설명, 리뷰 의견 반영까지 완료해야 해당 주차 과제가 끝납니다.

### GitHub와 Notion의 역할

| 구분 | 남길 내용 |
| --- | --- |
| **GitHub** | 완성 코드, 실행에 필요한 설정·의존성, 실행 설명, 결과 영상·스크린샷, 해당 과제의 정책 파일 |
| **Notion** | 참고한 교보재, 학습 과정, 실험·학습 로그, 오류와 해결 과정, 다음 할 일, PR 링크 |

Notion은 강의 내용을 전부 필사하는 용도가 아닙니다. **무엇을 시도했고, 어떤 결과가 나왔으며, 어디에서 막혔는지**가 보이도록 기록합니다. 최종 실행에 필요한 설정은 로그와 구분하여 GitHub에도 남깁니다.

### GitHub 제출 위치

```
AIstudy/
├── Week1/
│   └── 본인이름/
├── Week2/
│   └── 본인이름/
└── Week3/
    └── 본인이름/
```

- 매주 개인 작업 브랜치에서 작업하고, 본인 폴더의 변경 사항을 PR로 제출합니다.
- 기존 주차의 코드를 활용했다면 해당 위치를 명시하고, 이번 주차의 변경 사항을 설명합니다.
- 가상환경 폴더·캐시·불필요한 중간 파일은 업로드하지 않습니다.
- 영상·정책 등 큰 파일의 업로드 방식은 저장소 운영 기준에 맞춰 별도 안내합니다. 해당 주차 README와 PR에서 결과물에 접근할 수 있어야 합니다.

### 매주 PR에 포함할 내용

1. **과제 목표와 구현 내용**
2. **본인이 작성하거나 변경한 부분** — 제공 코드와 구분
3. **실행 환경과 실행 방법**
4. **결과물 및 실행 확인 결과**
5. **개인 Notion 학습 페이지 링크**
6. **미완료 항목 또는 질문** — 있는 경우

아래 기한은 **1차 PR 제출 기한**입니다. 리뷰 반영 기한은 리뷰 시 안내합니다. 기한까지 해결하지 못한 경우에도 시도한 코드와 오류·진행 상황을 제출하고, 모임에서 해결 후 보완합니다.
